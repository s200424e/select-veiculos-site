# Select Veículos · protótipo do site

Protótipo de vitrine para a Select Veículos (Ceilândia Norte, Brasília-DF), feito para apresentação.

- `index.html`: o site inteiro (estoque, filtros, simulador de parcelas e painel do lojista).
- `fotos/`: uma foto por carro, com o nome do id do carro (`c01`, `c02`...).

O painel do lojista funciona em **modo demonstração**: adicionar, editar, remover e mudar status salva só no navegador de quem está testando. O botão "Restaurar estoque original", na aba Dados da loja, volta ao estoque inicial. Para o lojista editar de verdade, de qualquer lugar, o site precisa de um banco de dados online, como Supabase ou Firebase.

A logo é provisória, e algumas fotos de carros do mesmo modelo podem estar trocadas.
